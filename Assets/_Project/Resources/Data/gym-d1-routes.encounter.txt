# GYM. D1 — is "which route" a real decision?
#
# Experiment group of the D1 pair. Its control is gym-d1-flat, which is THIS
# MAP with the three routes made identical. Read them together or not at all.
# Plan: docs/06-validation/strategy-depth-plan.md §3.
#
# HYPOTHESIS
#   H-D1  Three routes of near-equal COST but different width / terrain /
#         exposure make units of different M+R choose differently, and choosing
#         wrong costs something measurable.
#
# FALSIFIED IF (any one)
#   F1  M6 top route > 70%                      -> route choice is fake
#   F2  the two players' route distributions differ by < 10 points
#                                               -> M+R does not drive the choice
#   F3  gym-d1-flat's M6 differs from this map's by < 10 points
#                                               -> the distribution is strategy
#                                                  preference, not the map
#
# INVALID IF
#   I1  M3 > 15 or unresolved > 5%   -> too big; the clock would be the variable
#   I2  EP lethal exposure <= 2      -> one mistake ends it, route choice drowns
#
# GEOMETRY. 13x12. A four-row wall band (y=2..5) with three lanes that stay
# separate until they rejoin on y=1, so picking a gap COMMITS you to a lane:
#
#   west  x=2       1 wide, road.    Gate exposure 2. Single file: two units
#                                    cannot pass abreast.
#   mid   x=5,6,7   3 wide, road.    Gate exposure 3/4/3. Widest and most
#                                    watched.
#   east  x=10      1 wide, FOREST   Gate exposure 2, but 2 AP a cell.
#                   at y=4 and y=5.
#
# Measured with the paths sealed one lane at a time (not eyeballed):
#   west 9 AP   mid 10 AP   east 10 AP   -> 11% spread, inside the 20% the plan
#                                           asks for. What separates the three
#                                           is width, terrain and exposure.
#
# The block at x=4..8 / y=7..8 sits directly between the party and the mid lane
# on purpose. Without it the mid route is straight above the spawn and "which
# route" is arithmetic — the mistake gym-big-split made and M6 caught.
#
# EVERYTHING IS MIRROR-SYMMETRIC ABOUT x=6, AND BOTH PLAYERS SPAWN ON x=6.
# This is not decoration. Side-by-side spawns put one unit a cell closer to the
# west lane and the other a cell closer to the east, so the two would split by
# SPAWN POSITION and F2 would read as confirmed without M+R doing anything.
# Stacked on the axis, the only thing left that can separate them is reach.
#
# ROSTER. Two players chosen for their M+R, which is the whole of F2:
#   momotaro       MOVE 4 / range 1 -> M+R 5
#   kagemaru_plain MOVE 4 / range 3 -> M+R 7   (the SKILL-FREE Kagemaru)
# Skill-free on purpose: LegalCommands filters by AP, so a unit carrying skills
# enlarges the legal set the 15% noise samples from and changes the noise
# distribution for every strategy (playtest-metrics §21.1). The control kit is
# a second variable and this experiment has one.
#
# ENEMIES. Three, all mobile — no test_turret: scripted strategies will not
# advance to attack something that cannot come to them, and the result is a
# stalemate rather than a route (§17.5).
#
#   kohaku_1hit  M3/R1  ai=rusher    baseline melee threat
#   kohaku_bow   M3/R2  ai=rusher    the range differential
#   kohaku_bow   M3/R2  ai=cautious  aggression 40 -> arrives later
#
# DEVIATION FROM THE PLAN, stated rather than smuggled in: §3.2 asks for a
# kohaku_bowfair as the ranged unit and a plain M3/R1 rusher beside it. Both
# carry ATK 100, which puts Kagemaru's lethal exposure at 2 and trips I2 before
# a single battle runs. The band that clears I2 is ATK <= 75, and the only M3
# units in it are kohaku_bow (R2, ATK 70) and kohaku_1hit (R1, ATK 60).
# Measured EP: lethal exposure 8 (Momotaro) / 3 (Kagemaru), and both profiles
# have a non-zero residue.
#
# ⚠️ EXPERIMENT FILE, NOT STAGE 01. No clock, by design: shrinking the fight is
# what keeps the round cap off it (§3.0), and capping rounds to fix an
# instrument problem is the mistake §20.0 recorded.
#
#   #  Blocking   .  Road(1)   o  Open(1)   f  Forest(2)
#   Coordinates are (x, y), y = 0 at the TOP.
