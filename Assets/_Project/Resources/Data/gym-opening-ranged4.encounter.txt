# same map, same spawn cells, same AI profiles, same party, same objective.
# Ranged enemies go from 2 of 6 to 4 of 6.
#
# WHAT IT IS TESTING (playtest-metrics §18.4 / §19.1):
# five of the six enemies target whoever is NEAREST, so putting Zhengshou in
# front routes every hit into DEF 70 / HP 435 — party effective HP goes up
# four to five times using nothing but movement. Melee enemies are fully
# absorbed by that. Range 2 shoots the row BEHIND the blocker, so it is the
# direct counter.
#
# It also decides whether the taunt skill is worth anything: taunt sells
# "the enemy attacks who I choose", and right now positioning gives that away
# free. Tighten the routing rule and the exemption has something to exempt.
#
# READ IT WITH shield-wall. corridor-hold does not tank-route, so it cannot
# see this change; the strategy pair is the measurement.
