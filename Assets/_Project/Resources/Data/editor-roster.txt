# Ediki — Editor roster
#
# WHAT THIS IS
#   The Prototype Editor's answer to "which units belong to which side, and
#   which ids are the same character". Nothing else in the project needs that:
#   UnitDef carries no faction, and a battle decides sides per spawn line
#   (`spawn faction=player unit=...`). This file exists so the EDITOR can offer
#   a curated list instead of all 47 rows.
#
# WHAT IT IS NOT
#   It holds no stats and no rules. It only NAMES ids that must already exist in
#   units.txt, so it cannot drift from the numbers — the worst it can do is
#   reference an id that is gone, and the editor reports that as an error.
#   The game, Ediki.Sim and the test suite never read this file.
#
# FORMAT
#   character id=<key> name=<顯示名> faction=player|enemy|objective
#   variant   char=<key> unit=<units.txt id> label=<短標籤> note=<一句話>
#
#   faction=objective  props placed as protected targets. They are spawned on
#                      the player side with protect=true and do NOT count
#                      against the four-unit party limit, which is the same rule
#                      SquadMatrix uses when it swaps a roster.
#
#   No spaces inside any value — the parser splits on whitespace.
#
# UNITS NOT LISTED HERE still load and still play. They simply do not appear in
# the planner's palette. Old encounters that use them open normally.
#
# ---------------------------------------------------------------------------
# 我方 — 討鬼團
#
# The four are GDD-sourced: the character report names 桃太郎, 正守 (護行僧),
# 玄真 (大聖毫毛化身) and 影丸 (雉型忍者) and no fifth member. The same four are
# declared in code as SquadMatrix.Characters.
#
# A/B are two TACTICAL ROLES of one character, not two characters — units.txt
# calls them "one unit per TESTABLE role variant" and each pair differs in as
# few fields as its hypothesis allows.
#
# 正守 lists only Masamori_A/B (專案負責人 2026-08-18). The older `zhengshou`
# id is the same character — GDD romanises 正守 as "Zheng Shou" — but it is not
# offered here. Encounters that already use it still open and play.
# ---------------------------------------------------------------------------
