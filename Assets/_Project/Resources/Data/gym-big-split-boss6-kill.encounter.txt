# GYM. Rung 6 of the kill-target ladder — kill one 6-hit enemy, leave the
# other three standing.
#
# Identical to gym-big-split-boss6 except for the objective line and the mark,
# so the pair prices the victory condition on its own.
#
# WHY A LADDER AND NOT ONE BOSS. §11.2 already measured required hits as a
# CLIFF: 2 -> 3 took the win rate from 68% to 1%. A single hardness therefore
# cannot answer anything — at the top every objective loses, at the bottom every
# objective wins. Rungs 6, and the others beside it, exist to find whether the
# kill objective MOVES that cliff, which is the only version of the question the
# engine can actually answer.
#
# WHAT THE MODEL PREDICTS (docs/NOTE-2026-08-15-目標類型如何改變決策.md §3):
#
#     clear minion j  <=>  DPT_j x (rounds the target has left) > hits_j x target DPT
#
# The target needs 6 hits, i.e. ceil(6/2) player turns of standing next to
# things that deal 50 a hit. The harder the target, the longer the payback
# period, so clearing minions first should become correct somewhere up this
# ladder and be wrong at the bottom of it.
#
# The three unmarked kohaku never have to die. Under every rout encounter this
# project has ever run, "which enemies do I have to fight" had exactly one
# answer; the kill files are the first where it has more than one.
