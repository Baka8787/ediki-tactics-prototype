#        [counterCost=] [restCost=] [restHealPercent=]

#   ap               AP ceiling. Unspent AP CARRIES OVER up to this value.
#   apRegen          AP regained at the start of the unit's phase (added to what it

#   guardCost        OD-06 baseline: 3 AP -> halves incoming damage until next turn

#   restCost         Rest: heal restHealPercent of max HP, then stand down (OD-21).
#
# AP economy (OD-21, decided 2026-08-14): cap 10, regen 8.
# Regen below the cap is the point — banking 2 AP this turn buys a Rest next turn.
#

# --- 討鬼團, with the control kit (2026-08-15) ------------------------------
#
# WHY THESE FOUR EXIST NOW. The measured player loop was:
#   "walk to ~4 cells, wait for one minion, kill it in two hits."
# It is optimal for four separate reasons, and NONE of them is "not enough
# skills", so no damage skill would have touched it:
#
#   1. kohaku dies in exactly 2 hits = exactly one turn's attack budget
#      (regen 8 / cost 4), so EP residue is 0 and there is never a spare action
#   2. enemies close in unasked (OD-16), so waiting is free AND safer than
#      advancing, which would trigger several at once
#   3. pulling one at a time holds Exposure at 1, the minimum
#   4. banking AP buys nothing: no counter, and regen 8 covers two hits anyway
#
# So the kit below is three skills that all change WHEN an enemy can reach you,
# plus a striker who changes how many hits things take. Nothing here raises a
# damage number for its own sake — §11.2 measured required hits as a cliff, and
# a damage skill that beats the basic attack is just the new only answer.
#
# AP COSTS ARE CHOSEN, NOT GDD-SOURCED. 專案負責人 2026-08-15 指示先用合理值。
#
# ⚠️ REPRICED 2026-08-16 FROM MEASUREMENT, 2-3 AP -> 1 AP. See §21.
# The original reasoning below was "make the trade real". It was measured and
# the trade turned out to be a straight loss at every price:
#
#     skill cost   0(none)   1     2     3(was)  4     5
#     control-hold   51%    52%   44%    39%    38%   33%
#
# 1 AP is the break-even point and nothing above it is anything but a tax.
#
# THIS IS NOT A BUFF. Break-even means the skills now do NOTHING rather than
# costing 12 points, and that is the honest reading: they exempt limits that
# are not binding (H16 / §19.2). The price was never the problem — pricing
# them to 1 makes them harmless, not good. Making them good is upstream work,
# in the order NOTE-2026-08-16-H16 §6 lays out.

# --- kill-target ladder (2026-08-15) ---------------------------------------
# A kohaku that takes more hits. HP is the ONLY field that differs — same
# ATK 100, DEF 20, MOVE 3, same costs — so an encounter that swaps one in
# differs from the baseline in required hits and nothing else.
#
# Momotaro deals 60-20 = 40, so HP fixes EAtK exactly:
#
#   kohaku        80 HP -> 2 hits    the baseline minion
#   kohaku_3hit  120 HP -> 3 hits    reused as rung 3; already existed for the
#                                    divisibility experiments and matches kohaku
#                                    on every other field, so it fits the ladder
#   test_boss4   160 HP -> 4 hits
#   test_boss6   240 HP -> 6 hits
#
# The ladder exists because §11.2 already measured required hits as a CLIFF
# (2 -> 3 took the win rate 68% -> 1%), so a single hardness cannot tell you
# whether a kill objective changes anything: at the top of the ladder every
# objective loses, at the bottom every objective wins. The question is whether
# the kill objective moves the cliff, and only a sweep can answer it.
#
# A high-DEF wall would have been the obvious "boss" and is the wrong unit:
# every candidate in the roster (test_blocker ATK 40, kohaku_tank ATK 40) deals
# max(1, 40-50) = 1 damage to Momotaro, so skipping it would be free and the
# investment question would never arise. Hardness has to come from HP.

# --- SQUAD CRUCIBLE (2026-08-17) -------------------------------------------
#
# The four threats for gym-squad-crucible, one per lane, plus the shrine they
# are all ultimately aimed at. Every one is tuned against a SPECIFIC member of
# the 4x2 kit, so that no single answer covers the board:
#
#   sc_bruiser   180 HP  ->  Momotaro B's push (the chasm skips all 180 of it)
#   sc_shield    DEF 35  ->  Genjin B's break  (Kagemaru does 7 -> 27 a hit)
#   sc_assassin  MOVE 5  ->  Kagemaru A's slow (nothing else catches it)
#   sc_sniper    range 3 ->  Masamori A's taunt (nothing else reaches it in time)
#
# ⚠️ EXPERIMENT UNITS, and the enemy stat blocks have NO GDD source — they are
# built to a test-paper spec, which is why they carry the deliberately
# non-committal sc_ prefix rather than names that would imply a design.

# West lane. High HP so that killing it costs several actions — the point is
# that shoving it into the chasm costs one, which is the price comparison the
# lane exists to ask. ATK 85 hurts Genjin (50 a hit) and barely scratches

unit id=sc_bruiser  name=SC-Bruiser  hp=180 atk=85 def=20 move=3 ap=10 apRegen=8 range=1 attackCost=4 guardCost=3

#   Momotaro  60 ATK -> 25 a hit, broken 45  (x1.8)
#   Genjin    90 ATK -> 55 a hit, broken 75  (x1.4)
# The weakest attacker gains the most, which is what makes the break a party

# --- AP ECONOMY A/B (2026-08-16) -------------------------------------------
#
# The B arm of the first Stage experiment: "does a 3 AP remainder every turn
# produce a decision the 4 AP economy does not have?" (prototype-loop.md,
# OD-33). It is the ONLY thing in this pair that differs.
#
# THIS IS A COPY OF momotaro WITH attackCost 4 -> 5 AND NOTHING ELSE.
# No skills, no stat edit. Compare the two lines directly:
#
#   momotaro      ... range=1 attackCost=4 guardCost=3 restCost=2 ...
#   momotaro_ap5  ... range=1 attackCost=5 guardCost=3 restCost=2 ...
#
# Momotaro_B was NOT reused for this: it carries pushCost=3, which would put a
# second variable (displacement) into a one-variable experiment.
#
# WHY THE NUMBER MATTERS. Both arms get the same 8 AP a turn (cap 10, OD-21):
#   4 AP -> 8 divides evenly    -> two attacks, remainder 0
#   5 AP -> 8 does not divide   -> one attack, remainder 3
# So the remainder's competitor is NEXT turn's second attack: holding >= 2 AP
# reaches the cap of 10 and buys a double attack, while spending it on movement
# or Guard does not. The trade-off moves from inside the turn to across turns.
#
# ⚠️ EXPERIMENT UNIT. attackCost 4 remains the baseline (OD-01). This line does
# not propose changing it, and nothing else in the project references this id.
unit id=momotaro_ap5 name=Momotaro-AP5 hp=300 atk=60 def=50 move=4 ap=10 apRegen=8 range=1 attackCost=5 guardCost=3 restCost=2 restHealPercent=10
