# 1. Into the Breach —— 完全確定性、完全資訊，仍然很難

`[B]` 它與本專案共享兩個前提：**沒有命中骰、沒有戰爭迷霧**，敵人**預告**下一回合要做什麼。
所以它是最有參照價值的一個。

| 機制 | 內容 |
|---|---|
| **棋盤** | **8×8** |
| **時限** | **5 回合**，之後存活的敵人自行撤退 |
| 🔴 **勝利條件** | **不是殺光敵人。** 是保護建築 —— 每毀一棟就掉一點電網，歸零就結束 |
| **敵人預告** | 精確顯示下一步要打哪一格 |
| 🔴 **刻意的資源不足** | 「遊戲被平衡成**玩家不可能保住所有東西**，有時候用一棟建築換位置與後續機會才是對的」 |
| **玩法哲學** | 「不要先問怎麼殺最多敵人，要問**怎麼取消傷害、怎麼移動威脅**；擊殺是後來的事，而且只有在它不製造更糟的問題時才做」 |

> `[C]` **對本專案最尖銳的一句**：
> 在 ITB 裡「殺敵」是**手段**，在本專案裡「殺敵」是**目的**。
> 只要殺敵是目的，**最大化每回合傷害就永遠正確**，於是集火永遠正確。
> `[A]` 這正是專案負責人一秒就找到的那個解。

# 2. Fire Emblem: Conquest —— 難在地圖，不在數值

`[B]`

- 公認系列最難，而評價普遍認為它同時是**地圖設計最好**的一作
- 🔴 **「地圖難不是因為敵人強，是因為地圖機制」** —— 幾乎每張圖都有自己的 gimmick
- **增援在敵方回合開始時出現，而且當回合就能行動** —— 玩家無法在它動之前處理掉它

> `[C]` 第二條直接對應專案負責人本輪的第 1 條結構約束（威脅排程）。
> `[A]` 而本專案的 `spawn ... turn=N` **已經實作**，目前只有 2 張圖用到。

# 3. 一般設計理論（支持性，非決定性）

`[B]`

| 概念 | 內容 |
|---|---|
| **Dominant strategy** | 不論對手做什麼都是最佳解的策略 ⇒ 玩法可預測、無趣，玩家不會再探索其他選項 |
| **Meaningful choice** | 大多數選擇都應該讓玩家**權衡有好有壞的後果**；只有一個好選項就不是選擇 |
| **Action economy** | 核心是「**行動不夠用來處理所有威脅**」，因此必須冒險 |
| **Zone of Control** | 相鄰敵人限制移動（常見規則：進入 ZOC 必須停止）。**沒有 ZOC，快速單位可以直接繞過並包圍，對手沒有反應機會** |
| **Attacks of opportunity** | 讓玩家必須權衡「這回合花光」vs「保留一部分」 |

> `[A]` **ZOC 缺席在本專案已經被獨立指認過**（[strategy-depth-plan §1.4](06-validation/strategy-depth-plan.md)：
> ZOC ❌「前排保護不了後排」；最小射程盲區 ❌；高低差 ❌；即死地形 ❌）。
> `[A]` 而目前「把正守放最前」有效**是倚賴敵人 AI 打最近的**（6 隻裡 5 隻）——
> **那是 AI 的性質，不是規則的性質。**

# 4. 對照本專案：最高槓桿的東西**已經做好而且沒在用**

`[A]` **repo 事實**：

| 機制 | 實作狀態 | 使用狀況 |
|---|---|---|
| **`objective type=defend`**（`protect=true` ＋ `turns=N`） | ✅ `Objective.cs` / `BattleSimulator.cs` | **77 張裡只有 1 張**（`gym-c-defend`） |
| **`objective type=survive`** | ✅ 已實作 | 🔴 **0 張** |
| **增援 `spawn ... turn=N`** | ✅ 已實作 | **2 張** |
| **`objective type=kill`**（斬首） | ✅ | 6 張 |
| `rout` | ✅ | **67 張** |

`[A]` **而且目標類型是本專案量到的最大單一槓桿之一**：
> 目標優先級（先打誰）的價格在 **`rout` 下是 0–5 個百分點**，
> 在 **`kill` 下是 25 個百分點**。**同一個旋鈕，換個勝利條件價格差 5 倍。**

> 🔴 `[C]` **結論**：不需要新機制、不需要動 Core、不需要 ZOC，
> **就能把「殺敵是唯一貨幣」這件事拆掉** —— 只要改 `objective` 那一行。
> A4 golden hash 不受影響（沒有動規則層）。

| # | 槓桿 | 成本 | 它拆掉哪一條「集火永遠正確」 |
