# 0. 為什麼需要真人

自動化跑分能回答 Q1 / Q3 / Q5。**Q2 與 Q4 只有真人能回答**：

| # | 問題 | 為什麼機器答不了 |
|---|---|---|
| **Q2** | 玩家會不會**自己發現**該怎麼站？ | AI 不會學習 |
| **Q4** | 失敗時歸因給**自己**還是**系統**？ | 歸因是心理現象 |
| **Q6** | 每回合有沒有真的在「想」？ | 只有本人知道 |

**現在還多了一個機器完全答不了的**：

> **Q7：技能該什麼時候放？**
> 腳本策略在這件事上連續失敗三次（反擊、淨化、控制技能）。
> 最近一次 `control-hold` 比完全不用技能還差 12 個百分點 ——
> **不是技能爛，是機器不會挑時機。**

# 1. 怎麼跑

Unity 按 **Play**。**畫面上不會有 UI** —— 所有資訊在 **Console** 視窗
（`Window > General > Console`，建議把它拉大）。

載入時 Console 會印出：操作表、圖形對照表、以及這張圖的完整名單。
之後**每回合開始印一次盤面**。

## 1.1 操作

| 鍵 | 動作 | 備註 |
|---|---|---|
| **`ESC`** | **叫出操作說明** | **`F1` 也可以**（見下） |
| 左鍵自己人 | 選取 | |
| 左鍵格子 | 移動 | 同時消耗 **AP** 與 **MOVE** |
| 左鍵敵人 | 攻擊（4 AP） | 距離不夠會自動先走過去 |
| **右鍵任何單位** | **查看資料** | 剩餘 AP、各動作消耗、技能說明。**不會動手** |
| 右鍵空地 | 取消釘選 | |
| `G` | 防禦（3 AP） | 受傷減半，到下回合 |
| `H` | 休息（2 AP） | 回 10% HP，**立刻結束這個單位的回合** |
| **`T`** | **嘲諷**（正守，2 AP） | 半徑 3 內的敵人下回合被迫打我 |
| **`F`** | **遲滯**（影丸，3 AP，射程 3） | **滑鼠指著目標**再按。它每格移動 +1 AP，持續一回合 |
| **`V`** | **擊退**（桃太郎，3 AP，射程 1） | **滑鼠指著目標**再按。推開 1 格，**零傷害** |
| `空白鍵` | 結束回合 | |
| `TAB` | 循環**敵方**範圍顯示 | 威脅 → ＋移動 → 關 |
| `Z` | 切換**我方**範圍顯示 | |
| `R` | 重開這張地圖 | |
| `F2` | 把盤面重印到 Console | |
| `F3` | 完整除錯面板 | |
| `1`–`9` `0` `-` `=` | 換地圖 | `-` 是新的候選開場關 |

> **被拒絕的指令會印在 Console 並附上原因。** 按了沒反應一定會有一行說明，
> 不會靜靜失敗。

> ⚠️ **ESC 為什麼還綁了 F1**：ESC 不完全是我們的。
> 編輯器的 Game view 會用它解除鎖定的滑鼠游標，獨立執行檔會用它離開全螢幕。
> 這個專案從來不鎖游標，所以實際上不會衝突 ——
> 但「說明鍵有可能安靜地沒反應」值得一行保險。

## 1.2b 畫面上還剩下什麼 UI

UI 大部分關著，但這三個一直在：

| 一直顯示 | 內容 |
|---|---|
| **頭上的血條** | 雙方都有。綠 → 黃 → 紅，由左往右縮 |
| **左下角單位面板** | 目前選取的單位：剩餘 AP／MOVE、這格被幾隻打得到、**每個動作的 AP 消耗與說明**，前面 ✔／✘ 表示現在按不按得動 |
| **右鍵釘選後** | 面板改看那一隻。看敵人時會顯示「你選的單位要幾刀殺得掉它」與「它每刀打你多少」 |

> 面板的技能說明是**從 UnitDef 直接生成的**，不是手寫的文案 ——
> 所以上面的數字一定就是模擬器會用的數字，改了數值也不會說謊。

## 1.2 怎麼看盤面（圖形對照）

沒有美術，所以三個獨立的視覺通道各講一件事：

| 通道 | 講什麼 |
|---|---|
| **形狀** | **方塊 = 近戰**／**膠囊 = 遠程**／**圓柱 = 不會移動** |
| **大小** | 底面積越大 HP 越多 |
| **顏色** | 哪一隻。**綠→紫是你的，紅→琥珀是敵人的** |
| 暗紅色 | 這隻敵人還沒醒（沒感知到你） |
| 黃色調 | 防禦中，或正在嘲諷 |
| 淡藍色調 | 被遲滯 |
| 特別高 | 這隻是目標（斬首關才有） |

**圓柱體最重要**：它 MOVE 0，**永遠不會過來**。
要不要進它的射程完全是你的選擇 —— 這是全遊戲落差最大的一個決定。

顏色對應哪隻，Console 的名單每次載入都會印，不用背。

## 1.3 格子顏色：移動範圍 vs 攻擊範圍

**「走得到」和「打得到」是兩件事**，差距就是射程。
射程 2 的弓手威脅的範圍比它走得到的範圍**每邊多兩格** ——
把兩者混成一片，這件事就完全看不見了。所以四種範圍分開上色：

| 格子顏色 | 意思 |
|---|---|
| **藍** | **你**這回合可以站上去（移動範圍） |
| **青** | **你**這回合打得到（含先移動再打）。藍色外面那一圈就是「射程」 |
| **紅** | **他們**打得到（移動＋攻擊）＝ Exposure |
| **琥珀** | **他們**走得到但打不到（按 `TAB` 兩次才顯示） |
| **洋紅** | **兩者都是** —— 你站得上去，而且會被打 |

> **洋紅色是這個遊戲每一個決定真正在講的東西。**
> 舊版把藍色畫在紅色上面，所以藍色永遠贏 —— **整個盤面最關鍵的一種格子是隱形的。**

**把滑鼠移到某隻敵人身上**，紅／琥珀會縮成**只有那一隻**的範圍。
六隻的聯集回答「還有哪裡安全」，單獨一隻回答「這東西下回合要對我幹嘛」——
你盯著它看的時候，想問的是後者。

## 1.3 兩個一定會搞混的地方

1. **AP 和 MOVE 是兩個不同的預算。**
   AP 決定「這回合能做幾件事」（上限 **10**、每回合恢復 **8**、**用不完會留到下回合**）；
   MOVE 決定「能走多遠」（每回合幾格，走完就不能再走，即使 AP 還有）。
2. **休息會結束這個單位的回合。** 它不是順手回血。

# 2. 戰棋的常見思路

**這一節是給沒玩過戰棋的人的。** 每一條後面都標了它在這個 Prototype 裡值多少
—— 有數據的就寫數據。

## 2.1 五個通用的（所有戰棋都適用）

### ① 先看「有幾隻打得到我」，再看「我打得到誰」

新手看敵人在哪，老手看**自己站的那格會被幾隻打到**。
按 `TAB` 開危險區，紅色的格子就是。

> **在這個專案，站位是量到最大的變因之一**：
> 同一張圖，會挑安全格的策略 80%，直接衝的 15%。**差 65 個百分點。**

### ② 開架之前先算「這隻要幾刀」

Console 每回合會印 `N hits from uX` —— 你選的單位要幾刀能砍死那隻。

**收不掉的架不要開。** 打到一半停手 = 你挨了一輪，對方一隻都沒少。
Into the Breach 整款遊戲建立在這條上：**多數機甲根本殺不掉眼前的敵人**，
所以問題從「打誰」變成「它最後會站在哪」。

### ③ 集火，但注意「整除」

兩個半血敵人比「一個死掉、一個滿血」危險得多 —— 半血的照樣打滿傷害。
**但**如果你這回合能打 2 刀而目標要 3 刀，那第 3 刀就得等下回合，
中間你白挨一輪。

> 這是本作最隱蔽的一條。小耗剛好 **2 刀死 = 剛好一回合的攻擊預算**，
> 所以以前永遠不會有「多出來的一刀要花在哪」的問題。
> 新關卡故意放了 3 刀的敵人來破壞這個整除性。

### ④ 誰站前面，是一個決定

四人隊最重要的新問題。DEF 高的吃傷害，脆的躲後面。
但敵人不會配合 —— 有些會專挑血少的打。

**`T` 嘲諷就是強制執行的手段**：花 2 AP，半徑 3 內的敵人下回合只能打正守。

### ⑤ 你決定何時接觸，你就贏了一半

戰棋的節奏由「誰先進入誰的射程」決定。
**只要敵人會自己走過來，這個決定就不是你的** —— 你只要站著等就好。

> ⚠️ **這正是本作到現在為止最大的問題**，也是為什麼新關卡放了圓柱體（砲塔）。

## 2.2 三個這款特有的

### ⑥ 控制技能買的是「時間」，不是「傷害」

`F` 遲滯和 `V` 擊退**都不減血**。它們把「它幾回合後打得到我」往後推一回合。

划不划算的算法很簡單：
> **多出來的那一回合，你能做的事，值不值 3 AP（＝大半個攻擊）？**

值的情況：你正在撤退、你差一回合就能先解決別的、或者它一過來就是兩隻夾擊。
不值的情況：它反正已經打得到你了 —— **遲滯已經接觸的敵人等於白花**。

### ⑦ 地形是成本，不是裝飾

森林每格 2 AP，道路 1 AP。**繞遠路可能比直穿便宜。**

> 而且這個專案量到地塊成本是**非單調**的：從 2 漲到 3 反而讓玩家勝率上升，
> 因為貴到一個程度之後**玩家可以選擇不過去，而敵人非過來不可**。

### ⑧ 留 AP 是一種資源

上限 10、每回合恢復 8。所以**這回合留 2 點，下回合就有 10 點**，
夠做兩次攻擊之外多一個技能。

> ⚠️ 以前留不留都一樣（沒有反擊、8 點反正夠兩刀）。
> **技能上線之後才第一次有意義** —— 這也是要驗證的事情之一。

## 2.3 新手（跟目前的你）最常見的一個陷阱

> **「走到敵人 4 格外，等它靠過來，下回合兩刀劈死。」**

這在舊地圖上是**最佳解**，而且它無聊 —— 四個原因：

| 為什麼它會贏 | 新關卡怎麼處理 |
|---|---|
| 小耗剛好 2 刀死 = 剛好一回合預算 | 放了 3 刀的敵人 |
| 敵人自己過來，等待免費 | 放了不會過來的砲塔 ＋ **20 回合上限** |
| 一次釣一隻 → 只被 1 隻打到 | 放了射程 2 的弓手，還有已經在你這側的側翼兵 |
| 留 AP 沒用 | 三個技能都要 2–3 AP |

**在新關卡（`-` 鍵）上，這個打法會輸。**
腳本跑分：守著等 29%，直接推進 56%。**這是全專案第一張「站定不動」不是正解的圖。**

# 4. 要觀察什麼

### 主要問題

**Q2 — 你花了幾回合才發現「站哪裡」重要？**
第一次玩不要先看 §2，照直覺打。打完記下第幾回合開始注意「被幾隻打到」。

**Q4 — 輸的時候覺得是誰的錯？**
「我算錯了」→ 好。「這根本不可能贏」→ 壞，記下是哪一刻讓你這樣想。

**Q6 — 每回合有沒有在想？**
有沒有連續三回合以上**沒有猶豫**就知道要做什麼？是哪幾回合？

**Q7 —（新）技能你按了嗎？什麼時候？**
- 三個技能各按過幾次？
- 有沒有哪一次按完覺得「這步很聰明」？
- 有沒有哪一次按完覺得「白花了」？
- **打 `=`（無技能）那場，有沒有哪個瞬間你想按技能但沒有？**

### 次要觀察

| 觀察點 | 為什麼要問 |
|---|---|
| 你有進砲塔（圓柱體）的射程嗎？第幾回合？ | **這是本關的核心決定** |
| 三條路線走了哪條？為什麼？ | 「走哪條」應該是決策不是隨便 |
| 有刻意留 AP 嗎？ | 技能上線後第一次可能有意義 |
| 四個角色你分得出來嗎？ | 圖形差異化夠不夠 |
| Console 的資訊夠不夠？缺什麼？ | UI 關掉之後這是唯一的介面 |
| 20 回合上限有壓迫感嗎？還是根本沒感覺？ | 時鐘只在預算緊時才有用 |
| 有沒有想做但系統不讓？ | 可能是規則缺口 |

# 6. 不用回報的事

**已知且刻意如此**，不是 bug：

| 現象 | 說明 |
|---|---|
| 全是灰色方塊、沒有美術 | 明確非目標 |
| 沒有音效、沒有動畫 | 同上 |
| **畫面上 UI 很少** | 2026-08-15 指示關閉大面板，資訊在 Console。`ESC` 看操作、`F3` 看完整除錯面板。血條與單位面板一直在 |
| 攻擊一定命中 | 刻意移除命中骰（OD-05） |
| 敵人一開始不動 | 要感知到你才會醒，但**不會永遠不動**（砲塔除外，它是永遠不移動） |
| 沒有成長、裝備、等級 | 還沒做，[OD-31](../OPEN-DECISIONS.md#od-31) 待裁決 |

# 7. 目前的自動化基準（供對照）

`gym-opening`，200 場/格：

| 策略 | 勝率 |
|---|---|
| 守勢（挑威脅最少的格子） | 29% |
| 威脅排序 | 32% |
| **會用技能的守勢** | **17%** |
| **衝鋒（直接推進）** | **56%** |

**如果你玩起來跟這些差很遠，那本身就是最重要的回報。**
特別是：**機器用技能反而更差（17% vs 29%）。如果你用技能打得比不用好，
那就證明問題在機器不會挑時機，不在技能本身** —— 那是這一輪最想知道的事。
