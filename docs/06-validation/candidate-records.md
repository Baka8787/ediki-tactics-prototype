# 1. 怎麼讀這份紀錄

每一筆的欄位定義見 [prototype-loop §7.1](../05-development/prototype-loop.md)。三個提醒：

1. **「尺度」那一欄不是形式。** `[A]` 本專案的 AP 尺度是**每回合恢復 8、上限 10、攻擊 4、防禦 3、道路每格 1**。

3. 🔴 **玩某張圖之前不要看它那一格的勝率**（[prototype-loop §4.3 P2](../05-development/prototype-loop.md)）。
   本檔的數字是給**設計實驗**用的，不是給**玩之前**看的。

## CR-10　污染強度與淨化定價
